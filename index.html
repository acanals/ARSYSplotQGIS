ARSYSplotQGIS

QGIS plugin for archaeostratigraphic exploration of excavation XYZ points: linked plan and sections, group and range filters, kernel density, PNG export and a lightweight 3D scatter. Part of the ArcheSystem suite (IPHES-CERCA URV). Counterpart of ARSYSplotLite.

Opens its own workspace. Nothing is added to the QGIS map canvas or layer legend.

Quick start

↑ Contents

  1. Load sample (bundled sample.csv), or Import CSV, or Use selected layer.
  2. Toggle Group chips; adjust X / Y / Z under Resources → Filter.
  3. Navigate: wheel = zoom, drag = pan; Zoom opens a large window; per-view Fit recentres.
  4. Optional: Density → On. Use Draw → None to see the surface alone.
  5. Optional: Stretch Z, Cross-view hover, Open 3D view.

Data

↑ Contents

Import CSV

Detects encoding (UTF-8 or Latin-1) and delimiter (comma, semicolon, tab or pipe). Map columns to:

FieldMeaning
P1 X/Y/ZObject centre, or start of a P1→P2 vector
P2 X/Y/ZEnd of P1→P2, or start of P2→P3 (optional)
P3 X/Y/ZEnd of P2→P3 (optional)
GroupClassification used for colour (material, level, taxon, …)

Layout is interpreted per row:

  1. P1 only — point; no orientation vector.
  2. P1 and P2, no P3 — file stores vector P1→P2; the plugin stores P1 as the midpoint, and the axis as P2→P3.
  3. P1 + P2 + P3 — unchanged: point = P1, vector = P2→P3.

After import, drawing always uses P1 as the point and P2→P3 as the vector. Extra CSV columns are kept as attributes on a private PointZ memory layer.

Use selected layer

Copies the selected QGIS point layer (geometry, attributes, style hints for group / size / P2–P3 fields when present) into the private workspace. The project layer is never modified.

Load sample

Bundled sample.csv (ArcheSite1, ~2 500 points). Columns:

p1x | p1y | p1z | p2x | p2y | p2z | p3x | p3y | p3z | material | categoria | taxo | nivell

P2/P3 filled only for nivell 1. Default Group field after load: material. Set Draw to Vectors/Both to see axes; filter Group → nivell = 1 to isolate them.

Resources panel

↑ Contents

Filter (XYZ)

Three double sliders clip the cloud in X, Y and Z (limits from available P1/P2/P3 or geometry).

Reset under Filter restores full X/Y/Z ranges only. It does not change Point size, Draw, groups, Density or Stretch Z.

Stretch Z

Vertical exaggeration on Longitudinal and Transversal only. Plan stays isotropic (true scale).

  • On + Factor — 1 = true scale; 2 = Z drawn twice as tall as X/Y, and so on.
  • Applies to screen, zoom windows, PNG export and density on those panes.
  • Tick labels remain real metres; the axis title shows the factor (e.g. Z ×5 (m)).
  • The paper scale bar uses the horizontal axis only (true map metres).
  • Reset sets Factor back to 1.

Useful when archaeological thickness is small relative to trench length/width: exaggeration makes contacts, floors and vertical clustering readable without changing the numbers on the axis.

Cross-view hover

With On, the record under the mouse on one main pane is marked on the other two (shared real XYZ). Zoom windows and density picking are not involved. Helps tie a find in plan to its position in both sections.

Density (KDE)

↑ Contents

Kernel density of the currently filtered points (QGIS Processing heatmap). Fill is the styled KDE raster; isolines are line overlays. Results stay inside the plugin.

ControlDescription
OnBuild or remove the density surface on plan and sections.
ShowHeatmap, Isolines, or Both.
FillBands = discrete colour classes; Cloud = smooth interpolation. Same underlying KDE.
Colour / InvertPalette (Viridis, Plasma, Magma, Inferno, Archeo, …). Invert flips low↔high.
Min / MaxOne stretch control for plan, X/Z and Y/Z. UI values come from the plan peak, then apply as fractions of each view’s own peak (Auto Max = 100% local peak). Below Min is not painted — avoids empty “noise” floor.
Auto (2%)Min ≈ 2% cumulative cut of positive plan cells; Max = plan peak.
RadiusKernel bandwidth in map units (how far each point “spreads”). Auto suggests radius and cell from the extent.
CellRaster resolution. Finer cells = sharper map, heavier compute.
KernelWeighting function — see below. Min/Max are recalculated when the kernel changes.
Isolines / LabelsNumber of contour breaks; optional value labels on lines.
OpacityHeatmap fill opacity; empty cells stay transparent.

Plan and sections do not share absolute KDE units. Sections adapt radius/cell so a circular kernel does not blow up along the short Z axis. Change Stretch Z after density is on: the surface is rebuilt so it stays aligned with the points.

Kernel functions and archaeology

↑ Contents

All five kernels are standard KDE shapes available in QGIS Heatmap. They differ in how weight falls off with distance inside the Radius — not in the archaeological meaning of “density”, but in how sharp or soft concentrations appear. Radius still dominates the scale of the pattern; the kernel chooses the profile.

KernelShape (within Radius)Practical effectArchaeological interest
Quartic (default) Smooth dome; weight → 0 at the edge Balanced smoothing; few artefacts Good first pass for occupation patches, spreads and general structure of the assemblage
Epanechnikov Parabolic; similar to Quartic, slightly different curvature Often close to Quartic on excavation clouds Useful cross-check: if the map barely changes, the pattern is robust to kernel choice
Triweight More peaked at the centre than Quartic Stronger local maxima; weaker skirts Emphasises dense cores (hearths, dumps, knapping foci) over diffuse background scatter
Triangular Linear falloff (tent) Sharper peaks than Quartic; still continuous When you want clearer separation between neighbouring clusters without a hard cutoff
Uniform Flat weight inside Radius; zero outside (“top hat”) Blockier surfaces; abrupt edges at Radius Closest to a “count in a search radius” reading — blunt patches, useful to compare with buffer-style reasoning

How to use them in practice

  • Start with Quartic + Auto Radius/Cell; read plan and both sections together.
  • If soft lobes merge distinct loci, try Triweight or Triangular, or reduce Radius.
  • If you need a conservative, radius-like envelope, try Uniform.
  • Always treat KDE as an exploratory visualisation of the filtered sample. Group filters and XYZ clips change the surface; document which subset you used.

Zoom, export and 3D

↑ Contents

Per-view Zoom

Enlarged window of one pane with Fit. Esc closes. Stretch Z and filters apply; Cross-view hover does not drive Zoom windows.

PNG export

Paper figure of the data frame (not a UI screenshot): background, title, subtitle, 96 / 150 / 300 / 600 dpi, metre axes and grid, 50 cm black-and-white scale bar (horizontal), group legend (title + glyphs; tall legends in columns below the plot), density legend when active.

3D view

  • Drag = orbit; pan; wheel = zoom; Fit; Export PNG; Esc = close.
  • Shares group colours and Draw mode; group visibility, point and arrow size can be adjusted in the 3D window.
  • Qt painter — does not use the QGIS 3D engine.
