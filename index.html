ARSYSplotQGIS

Archaeostratigraphic workspace for excavation XYZ points. Opens its own window; nothing is added to the QGIS map or legend.

Open the plugin

Toolbar icon, or Plugins → Vector → ARSYSplotQGIS.

Quick start

  1. Load sample (bundled sample.csv), or Import CSV, or Use selected layer.
  2. Turn group chips on/off. Drag the X Y Z sliders.
  3. Wheel zooms a view; drag pans; Zoom opens a large window; Reset restores the initial view.
  4. Optional: Density → On. Use Draw → None to see the surface alone.
  5. Optional: Open 3D view.

Data

Import CSV detects comma, semicolon, tab or pipe. Map P1 as the object centre. Optional P2 and P3 are the two ends of the orientation vector (P2→P3; if P3 is missing, P1→P2). Group is the colour class.

Sample columns: p1x | p1y | p1z | material | categoria | taxo | nivell.

Filters and draw

  • Group — field, coloured chips, All / None.
  • XYZ range — clip the cloud.
  • Adaptive frame — Off: full extent. On: zoom to the filtered cloud.
  • Draw — Points (P1), Vectors, Both, or None (for density).

Density

Kernel density of the filtered points. Stays inside the plugin.

  • Show — Heatmap, Isolines, or Both.
  • Min / Max — colour stretch on real KDE values. Below Min is not drawn. Auto = 2% cut and raster maximum.
  • Radius / Cell — bandwidth and cell size. Auto suggests values from the extent.
  • Kernel — Quartic, Triangular, Uniform, Triweight, Epanechnikov. Min/Max update for each kernel.
  • Isolines / Labels / Opacity / Colour — contour count, line labels, fill opacity, palette.

Export

Each view: PNG paper figure of the data frame (title, subtitle, background, 96–600 dpi) with metre axes, grid, scale bar and legend.

Requirements and licence

QGIS 3.22 or later (tested on 3.40). No extra Python packages. GNU GPL-2.0-or-later.
