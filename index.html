How to use ARSYSplotQGIS

ARSYSplotQGIS is a viewer for coordinated excavation records: each row is a point in space (finds, samples, measurements) from a site. It also displays vectors (P2→P3) when those coordinates are available — in the spirit of a vector archaeology concerned with taphonomic and tafo-sedimentary questions. This guide shows how to load data, use the three views, filters, density and profiles, and export paper figures. Button and menu names match the English interface.

What is this plugin?

ARSYSplotQGIS is first of all a point viewer. The points are the coordinated records of an excavation — each find or measurement with XYZ coordinates in the site reference system. In plan and in section you read where those records sit in space and how they stack in depth.

When the table also stores the ends of a piece (P2 and P3), the plugin draws the corresponding vectors. That supports a vector archaeology approach: not only where objects are, but how they lie — useful for taphonomic and tafo-sedimentary reading of the assemblage (fabric, preferential orientations, slope, depositional context).

Everything happens in a dedicated workspace inside QGIS, not on the main map canvas. Three linked views show the same dataset:

  • Plan — horizontal view from above: X left→right, Y bottom→top.
  • Longitudinal — vertical projection along X: X horizontal, Z vertical.
  • Transversal — vertical projection along Y: Y horizontal, Z vertical.

You can colour and filter by attributes (material, level, and so on), show points, vectors or both, exaggerate depth with Stretch Z, explore kernel density, cut an A–B profile, find a record, open a Zoom window or a light 3D scatter, and export a paper figure at a true scale (for example 1∶50 with a 50 cm scale bar).

The plugin opens in its own workspace window. Its drawings are not added to the QGIS map canvas or layer legend. When you choose Use selected layer, the plugin works with a private copy of the selected point layer; it does not modify the original project layer.
Everyday tip

Load the sample with Load sample, set Draw to Both, and switch Cross-view on. Move the pointer over a point in Plan: the same record is marked in the two sections — and, where P2/P3 exist, you can also see its vector.

  • Click the ARSYSplotQGIS toolbar icon, or open Plugins → Vector → ARSYSplotQGIS.

The screen

Left column

  • Dark / Light — changes the appearance of the plugin workspace. It does not change the exported page, which always has a white background.
  • ? — opens this user guide.
  • Load Data — brings data into the workspace. You can import a CSV or spreadsheet, load the bundled sample, or use the currently selected QGIS point layer.
  • Group — selects the attribute used to colour the points. The coloured chips show the available values and let you show or hide each value. Load colours… and Clear manage an optional .colors file.
  • Options — contains the General, Density, Find and Profile tabs. The footer contains Reset and To QGIS layer. The Open 3D view command is in General → View.

Right side

  • Three drawing panes — Plan, Long and Trans. Each pane has its own Zoom, Fit and Export controls.
  • Resources — controls the X, Y and Z range filters, vertical exaggeration (Stretch Z), Measure, Cross-view, Orientation → Recalculate and live Coordinates under the pointer. It also displays the density colour scale when Density is active, or the profile export controls (CSV / To QGIS) when a profile is active.

Moving around a drawing

  • Use the mouse wheel to zoom in or out. Click and drag to pan across the drawing. Click Fit to recentre the view and fit the data frame in the pane.
  • Zoom opens the selected pane in a larger floating window. Press Esc to close that window.
  • When Point info is enabled, move the pointer over a point and pause to display its attribute information.
Quick start

1. Click Load sample to open the example dataset. 2. In Group, click one or more chips to show or hide categories. 3. Under Resources → Filter, narrow the Z range to display a depth interval. 4. If needed, open Options → Density or Options → Profile to explore those tools. 5. When the Plan view is ready, click its Export button and try a 1∶50 figure.

Your data

There are three ways to load data into the plugin workspace:

  • Import — choose the File type first (CSV or Spreadsheet), then click Choose file…. For an Excel or ODS file, select the required Sheet. Next, match the source columns to the plugin fields for P1, P2, P3 and Group.
  • Load sample — loads the bundled sample.csv file, containing approximately 2 500 points. Use it to become familiar with the workspace and its controls before importing your own data.
  • Use selected layer — copies the currently selected QGIS point layer into the plugin's private workspace. The source layer remains in the QGIS project and is not edited.

To send data from the plugin back to the QGIS project, use Options → To QGIS layer in the footer. This creates a QGIS memory point layer containing the complete loaded table and all its attributes. The plugin's group visibility and X/Y/Z filters are not applied: the output contains the full dataset, not just the points currently visible in the drawings. The new layer can be used with QGIS Processing or GRASS. Because it is a temporary memory layer, save it to a permanent format such as GeoPackage if you need to keep it after closing QGIS.

What every row needs

Each record needs spatial coordinates so the plugin can place it in the drawings. In the ArcheSystem model the drawn point is always P1; when vector data exist, the vector is P2→P3.

  • p1x / p1y — horizontal coordinates in Plan (required for point-only imports).
  • p1z — height or depth. For points only (no P2/P3 mapped), Z may be omitted: missing or empty values are stored as 0. If you map vector columns (P2/P3), every used endpoint needs a full X/Y/Z, including P1 Z.
  • Alternatively, map complete P2 and P3 X/Y/Z (P1 can then be derived as their midpoint).

P2 and P3 are optional as a set and define the vector. Import normalises each row as follows:

  1. P1 only — drawn as a point; no vector. X/Y required; missing Z → 0.
  2. P1 + P2, without P3 — the file stores the vector as P1→P2. The plugin stores P1 at the midpoint and the vector as P2→P3 (X/Y/Z required on P1 and P2).
  3. P1 + P2 + P3 — kept as supplied: point = P1, vector = P2→P3 (X/Y/Z on all three).

If P1 is missing but P2 and P3 are present, P1 is calculated as the midpoint of P2→P3. The same rules are used in ARSYSplot and ARSYSplotLite.

When a row has a vector axis, the plugin also maintains G_orientacio (azimuth 0–360°, North = 0°, clockwise) and G_pendent (inclination 0–90° from horizontal). Finite values already in the file are kept on import; empty ones are filled with the improved method (see Drawing options). Use Resources → Orientation → Recalculate to overwrite them later.

Planar tables with only Easting/Northing (no elevation column) can be imported as P1 X/Y. All points then sit at Z = 0 until you supply real heights.

Any additional columns in the CSV or spreadsheet are retained as record attributes. These fields can be used to colour the data with Group or to search for records with Find.

Try the sample

The plugin includes a bundled example file (sample.csv, about 2 500 points). Click Load sample to open it and explore the workspace without using your own data: points, grouping, filters, density, and so on.

Every row has a P1 point. About 500 rows in archaeological level nivell = 1 also have P2/P3, so you can try vectors: set General → Draw to Vectors or Both. To see only those rows, set Group → Field to nivell and leave chip 1 on.

Colour by group

  • Field — selects the record attribute used to assign colours to the points. Depending on your dataset, this could be material, archaeological level, taxon or another categorical field.
  • Coloured chips — each chip represents one value in the selected field. Click a chip to hide that category; click it again to show it. Records with no value are grouped under (empty).
  • All / None — All makes every category visible; None hides all categories. Use these controls to reset the category selection or start a new selection.
  • Load colours… — loads an optional UTF-8 .colors file that assigns a colour and, optionally, a Point model shape to each field value. The same format is used in ARSYSplotLite and ARSYSplot. The bundled sample.colors shows the expected layout. Click Clear to remove it.

.colors format (shared by all ARSYSplot editions): UTF-8 text. A line with only a field name starts a section. Under that section, each category is one line: value;colour;shape (shape may be omitted: value;colour). Colour is #rrggbb. The colours and shapes of a section apply only when that field is the active Group → Field. If you switch Group to another field, or a category value is not listed in the matching section, the plugin keeps its default colour and the current Point model shape.

Drawing options

The controls in General change how the loaded records are drawn and how the views are framed. They affect the plugin's display, not the source CSV, spreadsheet or QGIS project layer stored on disk.

  • Draw — chooses what is drawn in the views: Points, Vectors, Both or None. Choose None when you want to display density without the point and vector symbols. This is the first control in General. Opening the Density tab automatically selects None.
  • Point — sets the point-symbol size in millimetres and the symbol shape through Point model. Point info enables attribute information on hover; Large info changes the size of that information display.
  • Vector — arrowhead size (mm) and vector length. The geometric axis after import is still P2→P3, but the arrow sense follows the improved method (same as ARSYSplot): if the vertical component is significant and points “up”, the shaft is flipped so the tip follows the inclination / downslope sense. Fixed off (default): each arrow spans the real P2–P3 segment (possibly reversed). Fixed on: every arrow has the same Length (cm), centred on P1, along that directed sense — so you compare orientations, not object sizes.
  • View — configures the drawing frame and reference grids. Adaptive frame adjusts the frame to the displayed data; Axis grid shows metric coordinates. Archaeological grid draws excavation-square labels (for example R16) from the quadre (square) field: it only works when the loaded data include valid quadre (square) values that match the metre coordinates; without that field (or with empty/invalid codes) the switch has no effect. Z step sets the vertical-axis interval on the sections, either automatically or at a fixed interval in centimetres or metres. Open 3D view launches the separate 3D scatter window.
  • Redraw — exits the active Density or Profile display and redraws the loaded point data. Simply opening the General tab does not deactivate Density or Profile; use Redraw when you want to return to the standard point/vector views.
When to leave Adaptive off

For example, you want to compare a narrow Z interval with the complete section while keeping the same frame, coordinate axes and visual scale. Turning Adaptive off prevents the frame from adjusting to the smaller filtered subset.

Resources (filters, Measure, Orientation)

Filter

The Filter section contains three range controls, one each for X, Y and Z. Each control has two limits, so you can define the minimum and maximum coordinate to keep. Only points falling within all three selected ranges remain visible. Click Reset in the Filter section to restore the full available X, Y and Z ranges. This reset affects the coordinate filters only: it does not change Point size, Draw mode, Group visibility, Density settings or Stretch Z.

Stretch Z

Stretch Z is off by default. When enabled, it applies vertical exaggeration to the Longitudinal and Transversal sections only. The Plan view is not stretched and remains in its normal horizontal coordinate scale.

  • On / Factor — switch the effect on and set the exaggeration factor. A factor of 1 represents the true vertical scale; a factor of 5 draws the Z dimension five times taller relative to the horizontal X or Y dimension.
  • The coordinate tick labels continue to report real-world values in metres. The axis title indicates the applied exaggeration, for example Z ×5 (m), so the displayed height is not mistaken for the unexaggerated geometry.
  • The factor is applied consistently to the main section panes, their Zoom windows, density surfaces displayed in the sections, and paper exports of the Longitudinal and Transversal views.
  • On exported section figures, the scale bar refers to the horizontal axis and its true map distance. It does not represent the exaggerated vertical dimension.
  • Reset returns the factor to 1, removing vertical exaggeration.
When to use Stretch Z

A layer only 15 cm thick may look almost flat when shown along a long trench. Applying Stretch Z ×5 makes its vertical thickness easier to inspect, while the horizontal X or Y distances and their coordinate labels remain in real metres.

Measure

Click Measure, then pick A and B on Plan, Longitudinal or Transversal. The distance is reported in real metres (Stretch Z does not change the value). You can switch view at any time — that starts a new pair on the new pane. Press Esc or click Measure again to stop. Middle-drag still pans while Measure is active.

Orientation

Recalculate overwrites G_orientacio and G_pendent for every row that has a vector axis, using the improved P2→P3 method (same adaptive flip as the drawn arrows). Rows without an axis are skipped. Group and X/Y/Z filters do not limit which rows are updated — the full loaded table is considered.

Cross-view

Cross-view is off by default. When switched On, moving the pointer over a record in any of the three main panes marks the corresponding record in the other two panes. The link is based on the same real XYZ record, so you can identify its position across the three projections. Cross-view does not control or update the separate Zoom windows.

Coordinates

The Coordinates group shows the pointer position in real metres as three values in X Y Z order (for example 23.67 -- -378.47), while the mouse is over the plot frame of Plan, Longitudinal, Transversal or a Zoom window. Outside that frame the values show --. Stretch Z is removed from Z so the values match Measure and the data. Zoom windows use the same three-value line with a Coordinates: prefix in the top-right part of the window.

Density scale

When Density is displayed, the Resources area includes its colour scale and the Invert control. When a Profile is active, it instead provides Profile export options: CSV export and To QGIS for the LONG and/or TRANS section views.

Density

Options → Density builds a KDE surface (kernel density estimation) from the points currently included by the Group selection and X/Y/Z filters. There is no separate On switch: opening the tab calculates and shows the surface. The plugin calls the same QGIS Processing tool as Heatmap (Kernel Density Estimation): it creates a raster grid and, for each cell, adds a weighted contribution from every point that falls within the search Radius. Closer points weigh more; the Kernel function sets how that weight falls off with distance (Quartic, Epanechnikov, and so on). Cell is the raster cell size (resolution). The coloured heatmap is that raster after styling; Isolines are contour lines extracted from the same values. Density and Profile cannot be displayed at the same time. Selecting Density suspends the Profile display but keeps its A and B endpoints; selecting Profile restores the profile and hides Density. Opening General alone does not turn either off — use Redraw to return to the loaded point data.

  • Show — choose whether to display the coloured Heatmap, the density Isolines, or Both together.
  • Fill — selects how the heatmap surface is rendered. Bands displays discrete colour classes; Cloud displays a smoother, continuous-looking surface. Both styles use the same underlying KDE calculation.
  • Colour — selects the colour palette, for example Archeo or Viridis. Use Invert in Resources to reverse the direction of the selected palette.
  • Min / Max + Auto — defines the value range mapped to the colour scale. Auto proposes an automatic stretch, using approximately a 2% cut based on positive Plan cells and the peak value. Values below Min are not painted.
  • Radius + Auto — sets the search radius around each point, controlling the distance over which that point contributes to the density surface. Auto proposes a radius and also suggests a suitable Cell size.
  • Cell — sets the raster cell size, and therefore the spatial resolution of the density surface. Smaller cells produce a finer, more detailed raster but require more processing and memory.
  • Kernel — weighting function inside the Radius (same options as QGIS Heatmap). Radius mainly sets the spatial scale; the kernel sets how strongly a point still counts as you move away from it. Changing the kernel recalculates Min/Max.
  • Isolines / Labels / Opacity — controls the number of density contour lines, whether their values are labelled, and the opacity of the filled heatmap.

Kernel models available in the plugin (QGIS Heatmap):

KernelHow weight falls with distanceTypical look
QuarticSmooth bell that reaches zero at the Radius edge (biweight).Good general starting choice; balanced peaks and smooth flanks.
EpanechnikovParabolic curve that also reaches zero at the edge.Slightly flatter top than Quartic; common theoretical default in KDE.
TriweightLike Quartic but more weight near the centre.Sharper local peaks; surroundings fade faster.
TriangularLinear drop from the point to zero at the Radius.Simple cone-shaped influence; clear hard edge at Radius.
UniformSame weight for every location inside the Radius; nothing outside.Box-like discs; abrupt boundary, little internal grading.
Density values in Plan and in the vertical sections should not be compared as if they were the same absolute measurement: the views have different spatial dimensions and extents. In the sections, Radius and Cell are reduced to prevent a circular kernel from spreading excessively along the much shorter Z dimension. If you change Stretch Z while density is active, the density surface is recalculated so that it remains aligned with the displayed points.
Starting suggestion

As a first test, open Density, use Auto for Radius and Cell, select Heatmap with Bands, and choose Quartic as the kernel. Select Both if you also want the isolines drawn over the heatmap. Adjust Radius, Cell and the colour range after checking the result.

Profile

Options → Profile extracts a vertical slice from the point cloud. You define the slice by drawing a line between two endpoints, A and B, in the Plan view. The plugin selects points within a vertical prism centred on that line and displays their vertical distribution in the Longitudinal and Transversal section panes.

  • Wide (cm) — sets the horizontal width of the selection prism in the XY plane, measured perpendicular to the A→B line. The default is 10 cm, and the adjustment step is 1 cm. This value controls the width of the profile in plan; it is not a thickness measured along Z.
  • When you open the Profile tab, a blinking prompt in the Plan title bar asks you to place endpoint A (red). Click the required position in Plan, or enter its X/Y coordinates. The prompt then asks for endpoint B (blue). After B has been placed, the LONG and TRANS section views are generated or updated automatically.
  • To adjust an existing profile, move the pointer over endpoint A or B in Plan until the open-hand cursor appears, then drag the endpoint to its new position. The profile line and selection band follow the pointer; the section views are recalculated when you release the endpoint.
  • New Profile — removes the current A and B endpoints and the profile overlay, then starts a new selection by asking you to place A again.
  • The profile contains only records that pass the active Group selection and Resources filters and fall within the profile prism. The two section panes use the dominant direction of the A→B line for LONG (dominant Plan axis × Z) and the other Plan direction for TRANS (the other Plan axis × Z). Their coordinate ticks follow the same convention as Plan: numbers on X and letters on Y, with frames aligned to whole metres. For thin archaeological levels, the plugin automatically enables Stretch Z where needed to make the section legible. In Plan, the selected profile area appears as a green band, with A marked in red and B in blue.
  • While Profile is active, Resources → Profile export:
    • Export CSV… — exports the site records included in the current profile. The CSV contains the original attributes together with X/Y/Z coordinates, distance along A→B and perpendicular offset from the profile line. The default filename is original_SelectedProfile_YYYYMMDD.csv.
    • To QGIS… — creates one temporary point memory layer for each selected section (LONG and/or TRANS), using the point positions represented in that section view. It does not export the Plan XY geometry or P2→P3 vectors. Save the resulting layer or layers to GeoPackage if you need to retain them after closing QGIS.
  • Profile and Density are mutually exclusive display modes: activating one hides the other. Use General → Redraw to suspend both and return to the loaded point data. The profile definition — endpoints A and B, and the Wide value — is retained when you open Density or use Redraw. Returning to Profile therefore restores the same slice. Use New Profile when you want to discard that definition and start again.

Find a record

Open Options → Find to search the loaded records by their attribute values. The search looks for exact words or values in the available fields. Use AND (default) when all entered search terms must match, or OR when a record may match any one of them.

  • Matching records appear in a results table, with the attribute field names shown as column headers. Click a row to select that record, or press Enter to select the first result.
  • You can also click a plotted point in Plan, Longitudinal, Transversal or a Zoom window: the plugin opens Find, shows that record’s attribute fiche and highlights it with a green ring. (Measure and Profile pick take priority while they are active.)
  • The selected record is highlighted with a green ring in all three main views. The detail area below the results table displays the values of all its attribute fields.
  • If the selected record is currently hidden by a Group selection or an X/Y/Z range filter, the plugin can adjust the relevant visibility or range settings so that the record becomes visible in the drawings.

Saving a figure

Each main pane has its own Export button. You can also export from that pane's Zoom window. The export dialog creates a paper figure at a defined map scale, rather than simply taking a screenshot of the current window. The dialog title identifies the view being exported: Export · Plan, Export · Longitudinal or Export · Transversal.

  • Format and page — export as PNG or SVG, on an A5, A4, A3, A2 or A1 page in portrait or landscape orientation. The exported page background is always white, regardless of the workspace's Dark / Light setting.
  • Scale — choose Automatic to calculate a suitable 1∶N scale that fits the figure on the selected page, or Custom 1∶N to enter your own denominator. The default custom denominator is N = 20, but other values are allowed. Custom scale preserves the chosen N and displays the resulting physical drawing size.
  • Frame — draws a complete rectangular frame around the data area. The frame encloses the full footprint; it is not limited to the L-shaped coordinate axes.
  • Grid — adds metric grid lines and/or excavation-square divisions. These lines are drawn slightly thicker than the frame so that the grid cells remain legible in the exported figure.
  • Scale bar — the exporter normally uses a 50 cm black-and-white scale bar. At very small or very large 1∶N scales, it may choose a different length to keep the bar readable. The numerical scale (for example, 1∶50) is printed beside it.
  • Include legend — enabled by default. The legend identifies the Group categories using their assigned colours and Point model symbols. It is placed beside the drawing frame when there is enough space; otherwise, it is placed below the frame in columns.
  • Title and background — you can add an optional title and subtitle, and apply an optional fill colour to the plot area. The fill is restricted to the area inside the coordinate axes.
  • PNG resolution — choose 96, 150, 300 or 600 dpi. This setting controls the raster export resolution and is also used when sampling density for the paper figure.
  • Density — when density is active, the exported figure follows the density display on screen, including Stretch Z, the Min/Max colour range and palette inversion.
Example

For example, make the Longitudinal view active, enable Stretch Z ×5 and display Density as Both (heatmap and isolines). Click Export, choose A4 landscape, set the scale to 1∶50, select PNG and leave the legend enabled. The resulting figure is ready to insert into a report.

What it does not do

  • It does not add its drawings as map layers on the main QGIS canvas. Within ArcheSystem, the full desktop application for archaeostratigraphic analysis is ARSYSplot. This plugin is the QGIS companion viewer, not a replacement for that application.
  • The 3D view is a lightweight scatter plot implemented with Qt. It is not based on the QGIS 3D engine and does not provide the full functionality of that engine.
  • There is no separate “Arche10-only” import button. Arche10 is the ArcheSystem reference program for recording field data; its tables are fully compatible inside the suite. Exports from Arche10 can be loaded here as CSV (or spreadsheet). In the browser, ARSYSplotLite offers the Arche10 / Excel units workflow; this plugin reads Excel and ODS through QGIS GDAL/OGR.
