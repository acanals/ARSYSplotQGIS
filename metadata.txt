about=ARSYSplotQGIS is a QGIS 3 plugin developed as the QGIS counterpart of ARSYSplotLite, part of the ArcheSystem archaeological software suite developed at IPHES-CERCA URV.

    It provides an interactive archaeostratigraphic viewer for exploring and visualising the spatial distribution of archaeological remains recorded during excavation, in plan, vertical sections and 3D.

    WORKSPACE AND VIEWS
    - Opens in its own workspace, independent of the QGIS map canvas and layer legend.
    - Three linked 2D views: plan (X/Y), longitudinal section (X/Z) and transversal section (Y/Z).
    - Optional Stretch Z on the section views (vertical exaggeration; tick labels stay in real metres).
    - Optional cross-view hover: highlight the same record across the three main panes.
    - Optional 3D scatter view (X/Y/Z), with orbit, pan and zoom.

    DATA AND FILTERING
    - Import CSV files (comma, semicolon, tab or pipe delimiters), load sample data or use a selected QGIS point layer.
    - Map P1 (X, Y, Z) as the object position and optionally P2 → P3 to represent orientation vectors.
    - Colour points by group field (material, level, category, taxonomy, etc.).
    - Optional style file to set colour and marker shape per group.
    - Filter by group and X, Y and Z coordinate ranges.
    - Adaptive frame to fit the full or filtered dataset.

    DENSITY AND EXPORT
    - Kernel-density heatmaps and isolines, with five kernel functions.
    - Adjustable radius, cell size, colour palette, thresholds, isoline count, labels and opacity.
    - Independent zoom and PNG export for each 2D view, with configurable titles, backgrounds and resolution (96–600 dpi).

    REQUIREMENTS
    - QGIS 3.22 or later (tested with QGIS 3.40).
    - Uses the Python environment and Processing algorithms bundled with QGIS.
    - No additional pip packages, external binaries or internet connection required.

    SAMPLE AND DOCUMENTATION
    - Includes sample.csv. Select Load sample to explore the plugin.
    - Documentation: Help → Plugins → ARSYSplotQGIS or the project README (homepage).
