about=ARSYSplotQGIS is a QGIS 3 plugin for archaeostratigraphic reading of excavation point clouds.
    It opens its own window. Plugin layers are not added to the QGIS map canvas or legend.
    Three linked views: plan (X/Y), longitudinal section (X/Z) and transversal section (Y/Z), plus an optional 3D scatter.
    Load data with Import CSV (delimiter auto-detected: comma, semicolon, tab or pipe), Load sample, or Use selected layer.
    Map P1 as the object centre (X, Y, Z). Optionally map P2 and P3 as the two ends of an orientation vector (P2→P3; if P3 is missing, P1→P2).
    A group field (material, level, …) colours the points. Filter with coloured chips (All / None) and X, Y, Z range sliders.
    Adaptive frame: Off keeps the full extent; On zooms canvases to the filtered cloud.
    Draw points (P1), vectors, both, or none. Point size and arrow size apply to all views.
    Density: kernel-density heatmap and/or isolines of the filtered points (Quartic, Triangular, Uniform, Triweight, Epanechnikov).
    Min/Max clip the colour stretch on real KDE values (below Min is not drawn). Auto applies a 2 percent cumulative cut.
    Colour palettes, radius, cell size, isoline count, labels and opacity are adjustable. Density stays inside the plugin.
    Each view has a zoom window and PNG export (title, subtitle, background, 96–600 dpi) with metre axes, grid, scale bar and legend.
    3D is a built-in Qt orbit/pan/zoom scatter. It does not use the QGIS 3D engine and needs no extra Python packages.
    Requires QGIS 3.22 or later (tested on 3.40). Uses only the Python that ships with QGIS, plus the bundled Processing heatmap and contour algorithms.
    No pip packages, no binaries, no internet connection at runtime.
    Sample data (sample.csv) is included: p1x, p1y, p1z, material, categoria, taxo, nivell. Use Load sample.
    Documentation: Help → Plugins → ARSYSplotQGIS, or the README in the code repository (homepage).
